192.168.3.201 zhaohui-1

## 关闭swap分区
```shell
swapoff -a
sed -ri '/^[^#]*swap/s@^@#@' /etc/fstab
```

## 配置Hosts文件
```shell
cat >> /etc/hosts <<EOF
192.168.3.201 zhaohui-1  
192.168.3.202 zhaohui-2  
192.168.3.203 zhaohui-3  
EOF
```

## 网络访问测试
```shell
ping baidu.com
ping zhaohui-1
ping zhaohui-2
ping zhaohui-3
```

## 开启IP转发
```shell
cat <<EOF | tee /etc/modules-load.d/k8s.conf
overlay
br_netfilter
EOF

modprobe overlay
modprobe br_netfilter

cat <<EOF | tee /etc/sysctl.d/k8s.conf
net.bridge.bridge-nf-call-ip6tables = 1
net.bridge.bridge-nf-call-iptables = 1
net.ipv4.ip_forward = 1
EOF

sysctl --system
```

## 设置时区
```shell
# 上海时区
ln -svf /usr/share/zoneinfo/Asia/Shanghai /etc/localtime
date -R
```

## 添加Kubernetes源

apt-get update && apt-get install -y apt-transport-https

### 卸载原先的docker
```shell
apt-get autoremove -y docker docker-ce docker-engine  docker.io  containerd runc docker-ce-*

rm -rf /etc/systemd/system/docker.service.d

rm -rf /var/lib/docker
```

### 安装containerd
生成默认的配置
```shell
apt install -y containerd

# 生成默认配置
mkdir -p /etc/containerd
containerd config default | tee /etc/containerd/config.toml
```

### 配置containerd，使用阿里云镜像
```shell
# 修改config.toml文件，使用阿里云镜像
sed -i 's#sandbox_image = ".*"#sandbox_image = "registry.aliyuncs.com/google_containers/pause:3.9"#' /etc/containerd/config.toml

# 设置SystemdCgroup为true
sed -i 's#SystemdCgroup = false#SystemdCgroup = true#' /etc/containerd/config.toml
```

### 启动containerd
```shell
systemctl daemon-reload
systemctl restart containerd.service
systemctl enable --now containerd

systemctl status containerd

# 查看containerd版本
ctr version
```

# 初始化Kubernetes集群（Master）
## 使用 kubeadm 初始化 master 节点
在Master节点上使用kubeadm初始化集群
```shell
# 可以增加 --service-node-port-range=20000-40000 指定放开的端口范围，默认只能分配30000-32767
kubeadm init --kubernetes-version=v1.35.5 \
  --image-repository registry.aliyuncs.com/google_containers \
  --pod-network-cidr=10.100.0.0/16  \
  --service-cidr=10.200.0.0/16 \
  --service-dns-domain=cluster.local \
  --apiserver-advertise-address=192.168.3.201 
```

# 部署Calico CNI插件
## 下载Calico的资源清单并修改Pod网段
```shell
# 下载Calico资源清单
# 需要查找对应版本的calico插件，这里3.31.5适配1.35的k8s
kubectl create -f https://raw.githubusercontent.com/projectcalico/calico/v3.31.5/manifests/tigera-operator.yaml
wget https://raw.githubusercontent.com/projectcalico/calico/v3.31.5/manifests/custom-resources.yaml
```

```shell
# 修改文件中的Pod网段，匹配集群配置
grep 'cidr' custom-resources.yaml
#      cidr: 192.168.0.0/16
sed -i '/cidr/s#192.168#10.100#' custom-resources.yaml
grep 'cidr' custom-resources.yaml
#      cidr: 10.100.0.0/16
```

## 创建资源
下载镜像需要配置代理，无法配置就国内下载好导入。calico.tar.gz
可以在这里找对应版本 https://github.com/projectcalico/calico/releases
```shell
# 老版本只有一个镜像，新版本有多个镜像，反正一股脑加载进去吧。
# ctr -n k8s.io i import calico.tar.gz

tar zxf release-v3.31.5.tgz
cd release-v3.31.5/images
# release-v3.31.5\images\calico-cni.tar
# release-v3.31.5\images\calico-dikastes.tar
# release-v3.31.5\images\calico-flannel-migration-controller.tar
# release-v3.31.5\images\calico-kube-controllers.tar
# release-v3.31.5\images\calico-node.tar
# release-v3.31.5\images\calico-pod2daemon.tar
# release-v3.31.5\images\calico-typha.tar
for tarfile in *.tar; do \
  ctr -n k8s.io image import "$tarfile"; \
done
```

# 部署Nginx应用测试
## 编写Nginx资源清单
写一个nginx.yaml，定义Nginx的Deployment和Service
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
  labels:
    app: nginx
spec:
  replicas: 2
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: swr.cn-north-4.myhuaweicloud.com/ddn-k8s/docker.io/nginx:1.27.4-alpine
        ports:
        - containerPort: 80
---
apiVersion: v1
kind: Service
metadata:
  name: nginx-service
spec:
  selector:
    app: nginx
  ports:
    - protocol: TCP
      port: 80
      targetPort: 80
      nodePort: 30001   
  type: NodePort
```
## 导包并创建pod
```shell
ctr -n k8s.io i import nginx-v1.27.4.tar.gz

kubectl apply -f nginx.yaml
```
