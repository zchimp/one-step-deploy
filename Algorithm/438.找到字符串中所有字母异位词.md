
<a href="https://leetcode.cn/problems/longest-substring-without-repeating-characters/description/" target="_blank" rel="noopener noreferrer" style="font-size: 22px;">438.找到字符串中所有字母异位词</a>  
给定两个字符串 s 和 p，找到 s 中所有 p 的 异位词 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。  
  
示例 1:
```
输入: s = "cbaebabacd", p = "abc"
输出: [0,6]
解释:
起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。
起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。
```
 示例 2:
```
输入: s = "abab", p = "ab"
输出: [0,1,2]
解释:
起始索引等于 0 的子串是 "ab", 它是 "ab" 的异位词。
起始索引等于 1 的子串是 "ba", 它是 "ab" 的异位词。
起始索引等于 2 的子串是 "ab", 它是 "ab" 的异位词。
```
提示:
```
1 <= s.length, p.length <= 3 * 104
s 和 p 仅包含小写字母
```

# 暴力解法
思路：
1. 遍历字符串s 'cbaebabacd' 中有多少个 字符串p 'ab' 长度的子串
cb ba ae eb ba ab ba ac cd
    ```
    int length = p.length
    for (int l=0; l < s.length - length; l++) {
        sub  = s.substring(int l, int l+length);
    }
    ```
2. 判断子串和p是否为异位词  
  java截取词语 sub = s.substring(int beginIndex, int endIndex)  
  判断异位词的方法:
    ```
    # 1. 排序对比法
    char[] arr1 = sub.toCharArray();
    char[] arr2 = p.toCharArray();
    Arrays.sort(arr1);
    Arrays.sort(arr2);
    return Arrays.equals(arr1, arr2);

    # 2. 26个字母频次数组
    # 思路使用字符的ascii码减去小写'a'的ascii码，作为数组下标，sub有就加一，p有就减一，最后都是0
    int[] cnt = new int[26];
    for (char c : sub.toCharArray()) {
        cnt[c - 'a']++;
    }
    for (char c : p.toCharArray()) {
        cnt[c - 'a']--;
    }
    for (int num : cnt) {
        if (num != 0) return false;
    }
    return true;
    
    # 3. HashMap 兼容大小写、Unicode、中文通用 同理，放进去+1，拿出来-1
    Map<Character, Integer> map = new HashMap<>();

    for (char c : sub.toCharArray()) {
        map.put(c, map.getOrDefault(c, 0) + 1);
    }
    for (char c : p.toCharArray()) {
        map.put(c, map.getOrDefault(c, 0) - 1);
        if (map.get(c) == 0) map.remove(c);
    }
    return map.isEmpty();
    ```
实现：
```java
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> result = new ArrayList<Integer>();

        char[] template = p.toCharArray();
        Arrays.sort(template);

        for (int l = 0; l <= s.length() - p.length(); l++) {
            String substring = s.substring(l, l + p.length());
            char[] subChar = substring.toCharArray();
            Arrays.sort(subChar);
            if (Arrays.equals(subChar,template)) {
                result.add(l);
            }
        }

        return result;
    }
```

# 滑动窗口法
思路：
先统计 p 频次数组，初始化 s 第一个长度为 k 的窗口频次
窗口向右滑动时：只删左边出去一个字符、新增右边进来一个字符，单次修改仅 O(1)
对比频次是否一致，一致就记录下标
```java
# 使用ascii码替换int数组下标实现
import java.util.ArrayList;
import java.util.List;

public class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> res = new ArrayList<>();
        int sLen = s.length();
        int pLen = p.length();
        if (pLen > sLen) return res;

        int[] pCount = new int[26];
        int[] winCount = new int[26];

        // 初始化模式串频次
        for (char c : p.toCharArray()) {
            pCount[c - 'a']++;
        }

        // 先填满第一个窗口
        for (int i = 0; i < pLen; i++) {
            winCount[s.charAt(i) - 'a']++;
        }
        if (isSame(pCount, winCount)) {
            res.add(0);
        }

        // 滑动窗口向右移动
        for (int right = pLen; right < sLen; right++) {
            // 移出窗口左边界字符
            int leftOut = s.charAt(right - pLen) - 'a';
            winCount[leftOut]--;
            // 移入新右边界字符
            int newIn = s.charAt(right) - 'a';
            winCount[newIn]++;

            // 判断是否异位词
            if (isSame(pCount, winCount)) {
                res.add(right - pLen + 1);
            }
        }
        return res;
    }

    // 判断两个频次数组是否完全一致
    private boolean isSame(int[] a, int[] b) {
        for (int i = 0; i < 26; i++) {
            if (a[i] != b[i]) return false;
        }
        return true;
    }
}
```

```java
# 使用hashmap实现 使用map存储key+频次，map.equal相等即为异位
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> res = new ArrayList<>();
        int n = s.length(), k = p.length();
        if (k > n) return res;

        Map<Character, Integer> pMap = new HashMap<>();
        Map<Character, Integer> winMap = new HashMap<>();

        // 初始化 p 的频次
        for (char c : p.toCharArray()) {
            pMap.put(c, pMap.getOrDefault(c, 0) + 1);
        }

        // 初始化第一个窗口
        for (int i = 0; i < k; i++) {
            char c = s.charAt(i);
            winMap.put(c, winMap.getOrDefault(c, 0) + 1);
        }
        if (pMap.equals(winMap)) {
            res.add(0);
        }

        // 滑动窗口
        for (int right = k; right < n; right++) {
            // 移除窗口最左侧字符
            char out = s.charAt(right - k);
            winMap.put(out, winMap.get(out) - 1);
            if (winMap.get(out) == 0) {
                winMap.remove(out);
            }

            // 加入新右侧字符
            char in = s.charAt(right);
            winMap.put(in, winMap.getOrDefault(in, 0) + 1);

            // 两个map完全相等 = 异位词
            if (pMap.equals(winMap)) {
                res.add(right - k + 1);
            }
        }
        return res;
    }
}
```
