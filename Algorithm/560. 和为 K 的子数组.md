<a href="https://leetcode.cn/problems/subarray-sum-equals-k/description/" target="_blank" rel="noopener noreferrer" style="font-size: 22px;">560. 和为 K 的子数组</a>  
给你一个整数数组 nums 和一个整数 k ，请你统计并返回 该数组中和为 k 的子数组的个数 。  
子数组是数组中元素的连续非空序列。  
  
示例 1：
```
输入：nums = [1,1,1], k = 2
输出：2
```
示例 2：
```
输入：nums = [1,2,3], k = 3
输出：2
```
提示：
```
1 <= nums.length <= 2 * 104
-1000 <= nums[i] <= 1000
-107 <= k <= 107
```

# 暴力算法
思路：  
整数数组的连续非空子数组可双循环遍历得到所有结果。  
遍历过程中记录计算每个数组的和，为k则result+1；  
  
解法：
```java
public int subarraySum(int[] nums, int k) {
    int result = 0;
    for (int i = 0; i< nums.length; i++) {
        int temp = 0;
        for (int j=i; j< nums.length; j++) {
            temp += nums[j];
            // 不要加跳出条件，因为可能存在0等情况，需要全部遍历一遍
            if (temp == k) {
                result ++;
            }
        }
    }
    return result;
}
```

# 前缀和 + HashMap（最优 O (n)）
思路：
前缀和的定义是 preSum[i] = num[0] + num[1] + num[2] + ··· + num[i-1]  
这个好理解，就是前面所有数字加起来  
```
preSum[0] = 0
preSum[1] = nums[0]
preSum[2] = nums[0] + nums[1]
preSum[3] = nums[0] + nums[1] + nums[2]
```
区间[l,r]之间的子数组的和就是   
sum(l, r) = preSum[r+1] - preSum[l]  
这个理解就是 一个数组 [0 1 3 5 6 8]  
sum(3,5) = 3 + 5 + 6 = (0+1+3+5+6) - (0+1) = preSum[5+1] - preSum[3]

所以现在要求一个子数组的和等于k  
preSum[r+1] - preSum[l] = k  推导出=>  preSum[l] = preSum[r+1] - k

就是说**一个前缀和减去另一个前缀和等于k，则说明有一个区间的子数组和等于k**  
实际上就把问题转换成了，遍历数组，0 0+1 0+1+2 ... 计算前缀和，每次记录下前缀和，减去k，找一下之前记录，有没有相等的。

流程：
```
map 存放：前缀和值 → 该前缀和出现次数  
初始化 map.put(0, 1)：前缀和 = 0 出现 1 次（处理 preSum==k 的情况）
遍历累加当前前缀和 preSum
查找 preSum - k 是否存在 map，存在就累加对应次数
再把当前前缀和存入 map 计数
```
解法：
```java
import java.util.HashMap;
import java.util.Map;

public class Solution {
    public int subarraySum(int[] nums, int k) {
        Map<Integer, Integer> map = new HashMap<>();
        // 初始前缀和0出现1次
        map.put(0, 1);
        int preSum = 0;
        int res = 0;

        for (int num : nums) {
            preSum += num;
            // 找需要的前缀和 preSum - k
            int target = preSum - k;
            if (map.containsKey(target)) {
                res += map.get(target);
            }
            // 当前前缀和次数+1
            map.put(preSum, map.getOrDefault(preSum, 0) + 1);
        }
        return res;
    }
}
```
