<a href="https://leetcode.cn/problems/sliding-window-maximum/description/" target="_blank" rel="noopener noreferrer" style="font-size: 22px;">239. 滑动窗口最大值</a>  

给你一个整数数组 nums，有一个大小为 k 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 k 个数字。滑动窗口每次只向右移动一位。  

返回 滑动窗口中的最大值 。

示例 1：
```
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]
解释：
滑动窗口的位置                最大值
---------------               -----
[1  3  -1] -3  5  3  6  7       3
 1 [3  -1  -3] 5  3  6  7       3
 1  3 [-1  -3  5] 3  6  7       5
 1  3  -1 [-3  5  3] 6  7       5
 1  3  -1  -3 [5  3  6] 7       6
 1  3  -1  -3  5 [3  6  7]      7
```
示例 2：

输入：nums = [1], k = 1  
输出：[1]
 

提示：
```
1 <= nums.length <= 105
-104 <= nums[i] <= 104
1 <= k <= nums.length
```
# 暴力解法（大数据超时）
思路：  
滑动窗口 左指针l， 右指针r  
组成一个滑动窗口，每次滑动，循环统计区间[l, r]之间的最大值。
```java
public int[] maxSlidingWindow(int[] nums, int k) {
    int[] result = new int[nums.length-k+1];

    int l = 0;
    int r = k - 1;
    while (r < nums.length) {
        result[l] = nums[r];
        for (int m = l; m < r; m++) {
            result[l]=Math.max(nums[m], result[l]);
        }
        r ++;
        l ++;
    }
    return result;
}
```

# 单调递减双端队列（Deque）
增加一个单调递减的队列，保存可能成为最大值的数字，如果说这个数字没有可能成为最大值，那就直接抛弃掉。
例如 第一个窗口是3 1 2  
那么第一个数字3入队，第二个数字1，比3小，但是可能比后面一个数字大，则可能成为下一个窗口的最大值，所以也入队。  
第三个数字2,2比前一个数字1要大。下一个窗口移动，1会比2更靠前，可能被排除，而且1又比2小，所以1就已经不能成为下一个窗口的最大值了，所以把1去除，再对比3,3有可能成为最大值，所以不需要排除，2入队。  
当窗口移动的时候，我们需要看下队首位置的下标，如果下标大于左指针，那么队首位置的数字就要去除。  
```java
public int[] maxSlidingWindow(int[] nums, int k) {
    if (nums == null || nums.length == 0 || k <= 0) {
        return new int[0];
    }
    int n = nums.length;
    int[] res = new int[n - k + 1];
    Deque<Integer> deque = new ArrayDeque<>();

    for (int i = 0; i < n; i++) {
        // 1. 移除队尾所有小于等于当前值的元素，维持单调递减
        while (!deque.isEmpty() && nums[i] >= nums[deque.peekLast()]) {
            deque.pollLast();
        }
        deque.offerLast(i);

        // 2. 队首下标超出窗口左边界，移除过期最大值
        while (deque.peekFirst() <= i - k) {
            deque.pollFirst();
        }

        // 3. 形成完整窗口后，记录最大值
        if (i >= k - 1) {
            res[i - k + 1] = nums[deque.peekFirst()];
        }
    }
    return res;
}
```
