| 类型    | 含义     | 适用场景                                                     |
| ------- | -------- | ------------------------------------------------------------ |
| feat    | 新功能   | 新增页面、拓扑渲染、多集群接入、新接口                       |
| fix     | Bug 修复 | 资源关联错误、图表渲染崩溃、鉴权异常                         |
| docs    | 文档更新 | README、注释、部署教程、参数说明                             |
| style   | 代码格式 | 格式化代码、空格换行、注释调整，无逻辑改动                   |
| refactor| 代码重构 | 逻辑重写、模块拆分，无功能新增、无 bug 修复                  |
| perf    | 性能优化 | 集群缓存、渲染提速、减少 API 请求                            |
| test    | 测试相关 | 单元测试、e2e 测试、补充测试用例                             |
| build   | 构建工程 | Dockerfile、GitHub Actions、Go mod、镜像构建                 |
| ci      | CI 流水线| 修改 workflows、缓存、构建策略、密钥配置                     |
| chore   | 杂项维护 | 依赖升级、版本号、清理无用文件                               |
