The Graph
合约开发：使用Solidity语言；  
合约部署工具：可以选择Hardhat、Truffle或Foundry，建议使用**Hardhat**;  
数据聚合服务：选择The Graph提供的托管服务；  
数据聚合开发：The Graph给出的模板代码是TypeScript，因此这里使用TypeScript；  
前端页面：HTML+JavaScript/TypeScript，也可配合任意前端框架如Vue、React等；  
合约交互框架：虽然理论上使用JSON RPC就可以读写合约，但使用Ethers.js可以大大简化开发；  
钱包支持：如果仅支持MetaMask，则使用Ethers.js已足够，如果要支持多种钱包，尤其是需要连接手机钱包，则需要使用Web3Modal。  

Solidity语言；
JavaScript语言；
TypeScript语言；
HTML/CSS等前端技能。

将所有源码托管在GitHub；
使用The Graph提供的Hosted Service；
使用GitHub Page实现静态页托管；
可选：绑定一个域名。

# 智能合约开发
```
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

import "@openzeppelin/contracts/token/ERC20/ERC20.sol";

contract MyToken is ERC20 {
    constructor() ERC20("MyToken", "MTK") {
        _mint(msg.sender, 1000000 * 10 ** decimals());
    }
}
```
开发工具
Hardhat/Foundry：编译、测试、部署
OpenZeppelin：安全合约库（ERC20/721/1155）
安全工具：Slither（漏洞扫描）

# 前端开发
```
import { RainbowKitProvider, ConnectButton } from '@rainbow-me/react';
import { WagmiConfig, createClient } from 'wagmi';

const client = createClient({ autoConnect: true });

function App() {
  return (
    <WagmiConfig client={client}>
      <RainbowKitProvider>
        <ConnectButton />
      </RainbowKitProvider>
    </WagmiConfig>
  );
}
```
