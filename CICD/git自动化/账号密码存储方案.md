# 直接创建k8s secret
```shell
kubectl create secret docker-registry acr-secret \
    -n xxxx \
    --docker-server=registry.cn-hangzhou.aliyuncs.com \
    --docker-username={your_username} \
    --docker-password={your_password}
# yaml中保存为
# {
#   "auths": {
#     "registry.cn-hangzhou.aliyuncs.com": {
#       "auth": "base64(用户名:密码)"
#     }
#   }
# }
```

```yaml
# 配置文件中直接引用
spec:
  template:
    spec:
      imagePullSecrets:
        - name: acr-secret
```
